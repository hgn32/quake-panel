# Raspberry Pi 4 キオスク設定

フル HD モニターに常時表示するための設定例。表示専用なので Pi 側では
一切データ取得を行わない (取得は N150 サーバーが一手に引き受ける)。

## Chromium の起動

`quake-panel-kiosk.sh` を自動起動に登録する。要点は以下の 3 つ。

- `--autoplay-policy=no-user-gesture-required`
  通知音を鳴らすためのユーザー操作待ちを省く (§4)。この指定が無い場合でも
  画面をタップすれば有効化できるようになっているが、無人運用では指定しておく。
- `--kiosk` と各種ダイアログ抑止
  無人運用でクラッシュ復元バーや翻訳バーが出ると画面が崩れる。
- スクリーンブランク無効化
  常時表示が目的なので、DPMS とスクリーンセーバーを止める。

Basic 認証を通すため、URL に資格情報を埋めるのではなく Chromium の
プロファイルに保存された認証情報を使う (初回だけ手動でログインする)。

## 動作確認したい項目

- 平常時の CPU 使用率 (受け入れ条件 §6)。`top -b -n1 -p $(pgrep -f chromium | head -1)` で確認する。
- 72 時間放置後にメモリが増えていないこと。`ps -o rss= -p <pid>` を定期記録する。
- ネットワーク断からの復帰。LAN ケーブルを抜いて数分後に戻し、自動再接続することを見る。
