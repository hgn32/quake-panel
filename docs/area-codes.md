# 地名の値域 (上流 API の pref / name に何が入るか)

上流 API は同じ「宮崎」を、フィールドによって **宮崎 / 宮崎県 / 宮崎県北部平野部**
と書き分けてくる。どれもコード表で決まった有限の集合で、照合の実装 (利用地の県との
突き合わせ) がこの違いに依存する。**この文書はその値域の全列挙**である。
エンドポイントの仕様は [kmoni-endpoints.md](kmoni-endpoints.md) を参照。

調査日 **2026-08-20**。出典と再取得手順は §7。

---

## 1. フィールドと名前体系の対応

|---|---|---|---|---|

| P2P 551 `points[].addr` (`isArea: true`) | 地震情報／細分区域 | 188 | 宮崎県北部平野部 ほか 3 区 | §2 |

**556 `areas[].pref`** (警報対象かどうか)、**552 `areas[].name`** (津波予報区の強調) の
3 つだけ。残りは表示専用なので、表記が変わっても鳴動や絞り込みには影響しない。

## 5. 津波予報区 (98) — 552 `areas[].name`

**全 98 区の一覧はここには置かない**。同じコード表 (シート31) から起こしたものが
`shared/test/jma-tsunami-areas.json` にコードと注記つきで入っており、
区と県の対応は `shared/src/tsunami.ts` が唯一の定義で、全区を突き合わせるテストが
`shared/test/tsunami.test.mjs` にある。二重管理を避けるためそちらを一次資料とする。

表記の型だけ整理しておく。

- **県名そのもの**: 宮崎県、岩手県、大阪府 など
- **県名で始まる**: 熊本県天草灘沿岸、千葉県九十九里・外房 など
- **県名を含まない (7 区)**: オホーツク海沿岸、東京湾内湾、伊豆諸島、小笠原諸島、
  沖縄本島地方、大東島地方、宮古島・八重山地方
- **複数県にまたがる結合表現**: 有明・八代海 (福岡・佐賀・長崎・熊本)、九州地方東部 など

県名の部分一致で拾うと「大阪府」の設定に「大分県瀬戸内海沿岸」が当たるため、
実装は完全一致 + 県ごとの展開表で扱う。

| シート | 内容 | 件数 | この文書での使用箇所 |
|---|---|---|---|

気象庁のサイトは開発環境のプロキシから到達できなかったため、実際に読んだのは
CSV 変換版 (`kazumi/jmacsv`)。取得コマンド:

```bash
# 例: シート22 (府県予報区) と シート23 (都道府県)
curl -sL https://raw.githubusercontent.com/kazumi/jmacsv/master/EarthquakeVolcano-22.csv
curl -sL https://raw.githubusercontent.com/kazumi/jmacsv/master/EarthquakeVolcano-23.csv
```

二次資料でしか読めていないため、次の 4 点を独立に突き合わせて裏を取った。

| 突き合わせ | 結果 |
|---|---|
| シート22 のコードと名称 vs 気象庁防災情報発表区域データセット (NII geoshape) | `9450 宮崎` / `9440 大分` / `9014 北海道道東` / `9012 北海道道南` が一致 |
| シート22 の名称 vs 実電文 (2026-07-29 の警報) | `areas[].pref` = `熊本` が一致 (`server/test/p2pParse.test.mjs`) |
| シート24 の細分区域名 vs 実電文・実データ | `熊本県熊本` `熊本県球磨` (556 `name`)、`熊本県天草・芦北` `日高地方東部` (551 震度速報の `addr`) が一致 |
| シート23 の 47 都道府県 vs 背景地図 (`client/public/assets/japan-map.json`、国土数値情報由来) | 名称・JIS コードとも 47 件すべて一致 |

公式スキーマ (P2P地震情報 JSON API v2 の OpenAPI 定義) はフィールドの意味の出典:
<https://raw.githubusercontent.com/p2pquake/epsp-specifications/master/json-api-v2.yaml>

コード表が改定される (区の統合・新設) と表示や照合が合わなくなる。
表示がおかしいときはこの手順で原表を取り直し、§3 の表と
`shared/test/jma-eew-local-areas.json` を更新すること。
